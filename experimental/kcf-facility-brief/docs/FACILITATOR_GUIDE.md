# 진행자 안내 (Facilitator guide) — 훈련용 시설 이송 브리핑

**훈련 · 가상 상황 · 실제 상황 아님.** 이 자료는 연구용 시안이며 어느 기관도 승인하거나 검토하지 않았습니다.
참가자의 실명, 소속 연락처, 실제 입소자 정보는 기록하지 않습니다.

## 준비 (5분)

1. `viewer.html` 을 오프라인으로 엽니다. 인쇄본을 쓸 때는 `examples/delayed_vehicle/` 의 PDF 를 사용합니다.
2. 사례 1(2호차 지연)을 고릅니다. 먼저 **변경 전(기준)만 보기**를 켠 상태로 시군 담당자 화면을 보여 줍니다.
3. 진행자가 `handoff_30s_after.txt` 를 소리 내어 한 번 읽습니다(약 30초). 그다음 변경 후 화면이나 인쇄본을 건넵니다.
4. 시간 원점(T0)과 화면 맨 위의 '훈련' 표시를 함께 확인합니다.
