# synthetic-truth experimental overlay

Opt-in research code. Evidence and producing commands: research/synthetic-truth/README.md. Overall track status is HOLD_PARTIAL; see research/scenario-members/TRACK_STATUS.json for exact completed and open requirements.

Use Python 3.12 with NumPy 1.26.4 and the routing constraints. Forecast export requires the separate pinned forecast environment. Add this overlay's src plus the scenario-members, sipp-routing and synthetic-truth sibling src directories to PYTHONPATH for tests. No frozen kit or checkpoint is changed. The opt-in experimental/scenario-members/export_v3.py wrapper preserves the frozen integration exporter and its publication identity.

This code concerns represented models and source support, not physical safety. Unknown source fields remain unsupported; capped computation remains unresolved. No new checkpoint default or application policy is promoted.

The independent loaders live in `wfg_synthetic_truth.adapters`; GIS dependencies are pinned separately in requirements-gis.txt. GridSpec requires a north-up affine, an exact shape and projected metre EPSG. Sources are read once, SHA256-bound, optionally checked against a supplied expected digest, and refused if their source identity or bytes occur in the declared planning identities. No implicit resampling occurs.

- reconstructed_arrival reads an arrival GeoTIFF with explicit origin, cutoff and seconds/minutes/hours units. Nodata and negative raw arrival values remain unknown. Optional aligned standard deviation gives descriptive bounds rather than a calibrated confidence interval. Pre-cutoff arrivals retain negative relative seconds.
- observed_perimeters reads WGS84 GeoJSON with aware time_utc and unique source_record_id fields. Cell-centre mapped extents imply only conditional publisher-clock upper bounds; the lower bound is negative infinity. Unmapped cells remain unknown because the archive supplies no survey-negative footprint. Invalid geometries retain their IDs and validity diagnostics and make the complete collection unscorable. No geometry repair, exact ignition, extinction or flaming residence is invented.
- external_simulator reads stored FARSITE prediction NPZ plus its reference NPZ. It requires documented minute units, engine origin, negative no-burn sentinel and explicit Boolean simulation coverage. Covered sentinel cells are model-relative never; outside coverage is unknown. Stored coordinates, if present, are checked against the reference grid. Optional expected event and cutoff checks prevent mispairing. The reader runs no simulator and yields a deterministic arrival scenario rather than physical observations.

ArrivalTruth retains lower/upper arrival bounds, known and never masks, source bytes and interpretation. exact_ignition returns UNSCORABLE unless the arrival model is complete and point-valued. A returned MODEL_RELATIVE_ARRIVAL_ONLY still lacks the independent flaming phases, residence, fuel and thermal law required to construct a full-policy truth packet. These interfaces do not turn a perimeter interval into a clairvoyant optimum or complete the gated routing-risk studies.
