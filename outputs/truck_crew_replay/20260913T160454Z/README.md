# truck_crew_replay 20260913T160454Z

Per-vehicle trip geometry for `web/truck_crew_replay.html`, written here because a
viewer opened in a sandbox cannot save the file the page offers. Rule and caveats:
`docs/truck_crew_replay.md`. Coordinates are WGS84 (EPSG:4326), reprojected from the
EPSG:5179 routing geometry. These are model trips on a committed forecast field, not
a record of any vehicle movement.
