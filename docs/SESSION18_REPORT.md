`scripts/check_declared_deps.py` 로 273개 `.py` 를 `ast` 파싱해 기계적으로

없고**, 게이트가 `engine=` / `driver=` 리터럴을 따로 스캔하기 때문에
드러났습니다.

⚠ **전이 의존성은 선언이 아닙니다.** `affine` 과 `fontTools` 는 설치되어
있었지만 rasterio·matplotlib 이 다음 릴리스에서 떼어내면 그대로 깨집니다.

⚠ **핀 출처를 정직하게 적습니다.** 새 핀 4개(affine 3.0.1, h5netcdf 1.8.1,
h5py 3.16.0, fonttools 4.63.0)는 **이번 세션 작업 환경(Linux aarch64, PyPI
휠, Python 3.11)에서 확인한 버전**이며, macOS/conda `wfg311` 참조 환경을
조회한 값이 **아닙니다**. 기존 핀은 하나도 움직이지 않았습니다.

**답은 (B), 구성상입니다.** `_evaluate_path` 는
`clearance = min(time_to_cutoff(node) − arrival(node))` 를 경로 노드 위에서
계산하고, `time_to_cutoff` 는 그 노드가 지평 안에 `p_cut` 에 닿지 않으면
`inf` 입니다. 즉 **유한한 마진은 경로 위의 노드가 타야** 나오는데,
**성공적으로 불을 피한 경로에는 그런 노드가 없는 경향**이 있습니다. 성공과
유한 마진은 서로를 밀어냅니다. 지평을 30→360분으로 세 배 늘려도 0→2 였습니다.

⚠ **죽은 코드 경로는 아닙니다.** 같은 함수가 Layer 2 에서는 유한 마진을
냅니다 — 커밋된 라우팅 아티팩트의 `clearance_margin_min` 8개 중 **5개가
유한**하고 −493.9, −209.0 도 있습니다. 차량은 불 쪽으로 들어가기 때문입니다.
**이 국면(중간 규모 타원 화재를 걸어서 피하는)에서 무력한 것이지 고장이
아닙니다.**

**점수 정의는 "생존 경로 없음 **또는** 마진 10분 미만"이지만, 영덕에서는
앞 절만 있는 것으로 읽어야 합니다.** `MARGIN_FAIL_MIN` 자리에 측정 증거와
함께 주석으로 남겼고, **정의를 지우지 않았습니다** — 지우면 이 절이 존재하고
휴면 중이라는 사실 자체가 사라집니다.

**아무것도 발화시키려고 건드리지 않았습니다.** 라우터·문턱·위험원 무변경,
기존 수치 무이동. 이 성분은 측정 전에도 후에도 0을 기여합니다.

## 주장하고 싶었으나 검증하지 못한 것 *(필수 항목)*

1. **"이 저장소는 어떤 노트북에서도 부팅한다"** — 주장하지 않습니다. 확인한
   것은 **Linux aarch64, PyPI 휠, Python 3.11.16, 한 번**입니다. macOS/conda
   `wfg311` 참조 환경에서는 **돌려보지 못했고**, 새 핀 4개의 버전도 그쪽에서
   조회하지 못했습니다. Windows 는 시도조차 없습니다.
2. **오프라인 검증은 프로세스 내부 차단이지 에어갭이 아닙니다.** 파이썬 소켓
   계층을 우회하는 경로(서브프로세스, C 확장이 직접 여는 소켓)는 **잡히지
   않습니다.** 정적 증거(외부 http 참조 0건)와 동적 증거는 **서로 다른
   종류**이며, 둘 다 있다고 해서 에어갭 증명이 되지는 않습니다.
3. **충돌 스윕의 0건은 부재의 증거가 아닙니다.** 도구는 문장을 읽지 못합니다.
   "pooled 수치는 0.905였다"처럼 키에 없는 말로 서술된 양은 **완전히
   투명합니다.** 튜닝을 5,622→6 으로 좁힌 각 단계는 노이즈를 줄였지만
   **동시에 탐지 범위도 줄였고**, 그 손실분을 정량화하지 못했습니다.
4. **매니페스트의 sha256 은 결정론 주장이 아닙니다.** 파일이 **변했다**는
   것을 잡을 뿐이고, 재생성 명령을 다시 돌리면 바이트 동일하게 나온다는
   보장이 아닙니다 — 일부 아티팩트는 타임스탬프를 품고 있습니다. 실제로
   재생성해 대조하는 검증은 **하지 않았습니다.**
5. **재생성 명령 8개는 `UNKNOWN` 입니다.** 추측으로 채우지 않았습니다.
6. **재현율 0.138 이 "나쁘다"고도 "괜찮다"고도 말하지 않습니다.** 비교
   기준이 없습니다 — Phase 4 의 비교 불가 주의가 바로 그 이유입니다. 아는
   것은 **AP 가 유병률의 8.6배**라는 것뿐이고, 그것은 순위에 실제 신호가
   있다는 뜻이지 운영 성능에 대한 판정이 아닙니다.
7. **`clearance` 진단은 영덕·타원 위험원 한 곳입니다.** Paradise 에서도,
   학습 위험원으로도 돌리지 않았습니다. "무력하다"는 **이 국면**의 측정입니다.
8. ⚠ **자진 신고 — 빨간 게이트 위 커밋 3건.** `dd315cc`, `5f2082f`,
   `0e467b4` 가 `check_forbidden` exit 1 상태에서 만들어졌습니다. 원인은
   제가 로그에 `154` 를 쓰면서 줄 프래그마를 빠뜨린 것이고, **놓친 이유가 더
   중요합니다**: Phase 0 는 게이트를 **로그 작성 전**에 돌리고 다시 돌리지
   않았으며, Phase 3 커밋은 게이트 종료 코드를 `for` 루프에서 **출력만 하고**
   커밋과 `&&` 로 묶지 않아 **exit 1 을 보고도 진행**됐습니다. Session 10 의
   파이프 사고와 **다른 형태의 같은 실수**입니다. 이후 모든 커밋은 단일
   `&&` 연쇄로 게이트를 통과시켰습니다. 되돌리지 않은 이유는 세 커밋의
   내용이 게이트와 무관하게 정상이고, revert 가 아니라 정정이 규칙이기
   때문입니다.
9. **Phase 2 가 커밋한 24개 중 6개는 브리프가 센 18개 밖**입니다(같은 실행의
   형제 산출물). 인용되지 않는 파일을 추가한 것이며, 최소 변경은
   아니었습니다.
10. **`preload(strict=False)` 의 부분 성공 경로는 합성 지역으로만
    시험했습니다.** 진짜로 절반만 로드되는 상황 — 한 지역은 되고 한 지역은
    안 되는 — 을 실데이터로 재현하지는 못했습니다.
