# Finals Demo (본선 시연 화면) · UI 아키텍처와 시각 방향

작성: 2026-08-15. 이 문서는 `web/finals.html`(빌더 `scripts/build_finals.py`, 템플릿
`scripts/finals.template.html`)의 설계 기록이다. 운영자 콘솔(`web/console.html`)은
그대로 보존하며, 본선 화면은 별도의 정적 단일 파일로 공존한다.

## 0. 한 문장

"불이 이미 발견되었다. 다음에 무슨 일이 일어나는가" 를 심사위원이 60~120초 안에
지도 위에서 이해하게 한다. 중심 문구: **「어느 길이, 언제까지 열려 있는가?」**

## 1. 강제 제약 (게이트)

- 완전 오프라인 단일 파일. `check_screen_assets.py` strict: 외부 URL 금지(SVG
  네임스페이스 2종 제외), `fetch(`·XHR·WebSocket·EventSource·sendBeacon·
  serviceWorker·`@import`·`url(http`·`srcset=`·`integrity=` 전부 금지(주석 포함).
- EM/EN 대시 금지(벤더 폰트 서브셋에 글리프가 없음). 범위는 `~`, 변화는 `→`(Arrow
  서브셋), 병렬은 `·`. 페이로드 문자열도 빌더에서 `_dash_safe` 정규화.
- `check_region_literals.py`가 빌더·템플릿을 스캔: 지역명·지역 종속 수치는 인용
  문자열에 하드코딩하지 않는다. 모든 표시는 정본 산출물에서 빌드 시점에 읽는다.
- 빌더는 `data/processed/`에 아무것도 쓰지 않는다(baseline 고정).
- 템플릿은 `scripts/`에 두고, 빌드 산출물에는 플레이스홀더가 남지 않는다.
- `make finals` 계약 유지: `build_finals.py --verify` 후 `check_screen_assets.py
  web/finals.html`. `--verify`는 빠른 게이트를 실제로 실행해 그 결과를 화면의
  SYSTEM INTEGRITY 패널에 기록한다(실행하지 않았으면 "실행 안 함"으로 표시).

## 3. 경험 구조

INTRO(선택, 6~10초, 즉시 Skip) → **LIVE**(기본) · SYSTEM · EVIDENCE · RELIABILITY
4개 세그먼트 탭. 탭 전환은 문맥 유지(가벼운 크로스페이드), 별개 페이지가 아니다.

### LIVE
지도가 주인공(시각적 비중 60~70%). 좌측 상단 지역 스위처(지역·연도·한 줄 설명),
하단 폭 전체 타임라인, 우측 판정 패널(선택 전에는 조용한 요약, 선택 후 결정 카드).

### 안내 시연 (Guided Demo, 4막)
- 1막 발견: 지도 위 트리거 화점(위성·시각·FRP는 viz.json 실측값) + "INCIDENT
  DETECTED". 5초 안에 상황 이해.
- 2막 시간이 도로망을 바꾼다: 타임라인 등장, 0→720분 진행. 위험면 확장과 함께
  도로 구간이 통행 가능→위험 대역→통행 불가로 전이. 전이 순간 짧은 펄스 + 폐쇄
  마커 + 타임스탬프. 이 화면의 서명 장면.
- 3막 경로 비교: 실측 경로쌍(naive vs 미래 인지)을 실제 기하로 그린다. STATIC
  VIEW(t=0 위험면만)와 TIME-AWARE VIEW 전환. naive 경로가 지평 내 위험 확률
  0.5를 넘게 되는 구간을 강조(빌드 시점 파생, 근거 명기).
- 4막 판단: 결정 카드(위치·경로 상태·소요 시간·폐쇄 시각·안전 경로 유무·근거
  한 줄) + "예측을 행동 가능한 판단으로 바꿉니다" → 자유 탐색 안내.

### SYSTEM
가로 6단계 인터랙티브 시퀀스: 감지 → 시간 위험면 → 시간 확장 도로망 → 경로
판정 → 운영자 판단 → 전달(승인 토큰). 호버·클릭 시 해당 단계 활성, 나머지 감쇠.
수혜자는 주민(특히 고령), 사용자는 운영자임을 명시.

### EVIDENCE
소수의 강한 카드만: LOFO AUC(폴드 평균·표준편차, pooled은 pooled로 라벨),
footprint IoU 약 0.40, 지역별 비교표(커버리지 동반, 순위 금지 문구), 구조자 노출
대비(짝지은 대비·합성 위험면 라벨), 경사 보정(표집 간격 동반), 실행 시간(재생 런
실측), 검증 레지스트리(147항목·재현 가능 131). 카드마다 「어떻게 측정했나」.

### RELIABILITY
한계를 제품 강점으로: 커버리지(영덕 32.6% 문구 그대로), 입력 민감도(이진 판정은
민감, 짝지은 대비는 강건), 실무자 평가 없음·운영용 아님, 대피소 레이어의 실체
(공원·정자 비중), 화재 경계 검증 한계(IoU 0.40, 외피 편향 부호 반전), 판정 이동
실측(90 대 1, 승인 문구), 배차 정렬 부정 결과(모서리 인용문), 자료 계보·재현성,
SYSTEM INTEGRITY(게이트 실행 결과 실측 기록).

## 4. 시각 방향

- 팔레트: 콘솔의 흑연 계열을 상속하되 한 단계 깊게. 배경 `#0a0e13`, 패널
  `#10161e`, 헤어라인 `#1c2733`, 본문 `#e8edf2`, 보조 `#8fa1b3`. 상태색은
  아껴서: 안전 `#22d3ee`(콘솔과 동일), 경로 정보 `#5b9cf6`, 시간 임박 `#f59e0b`,
  폐쇄 `#e0492f` 계열. 빨강은 브랜드가 아니라 사건에만.
- 타이포: IBM Plex Sans KR(400/600) + IBM Plex Mono(400/600) + Arrow 서브셋.
  위계: 시네마틱 헤드라인(수트 없이 큰 Sans 600) / 섹션 제목 / 압축 라벨(11px,
  자간 넓힘, 대문자·한글 혼용 절제) / 큰 수치(Mono 600, tabular) / 메타(12px).
  모노스페이스는 시간·좌표·계산 상태·해시에만.
- 모션: 150~300ms 기본, 서사 순간만 600~900ms. transform·opacity만. 폐쇄 펄스는
  1회성. `prefers-reduced-motion` 전면 존중(전이 즉시 완료).
- 지도 위계: 지형 음영(저대비) → 도로망(상태별) → 위험면 → 선택 경로 → 출발지
  → 대피소·화점 → 주석. 무선택 시 조용하게, 선택 시 무관 기하 감쇠.
- 아이콘 없음: 콘솔 규약대로 색+모양+텍스트 삼중 부호화(● ▲ ■ ◆, 도로 상태는
  색+선 스타일+텍스트).
- 해상도 목표 1366×768 / 1440×900 / 1920×1080, 핵심 시연 중 세로 스크롤 없음.
