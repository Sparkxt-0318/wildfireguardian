# R1 — ISEF precedent for Korea Code Fair (KCF) qualifiers, 2022–2026

Compiled 2026-09-03 from primary sources: Society for Science finalist directories / program books (PDF, sspcdn), the ISEF Projects Database (abstracts.societyforscience.org, POST search FairCountry=South Korea), Society for Science full-award and special-award press releases, 과기정통부 press releases on korea.kr (hwpx attachments unzipped and read), kcf.or.kr pages, and Korean news. Raw files: `research/isef_dirs/`, `research/awards/`, `research/abstracts/korea_rows.json`, `research/kcf/`.

Blunt summary: KCF has sent 5–7 teams per year to ISEF since 2022 (fair ID **KOR001, "Korea Code Fair", Daegu**). Every year exactly one KCF-route project has won a Grand Award, always 4th–2nd place, never 1st; the rest go home with nothing or a small special award. All six Grand-Award winners are **assistive/health technology for a specific vulnerable group, with a physical device or a live app, and a measured human outcome**. Zero KCF-route projects have entered EAEV/ENEV (earth/environment); the KCF pipeline officially mentors toward EBED, SOFT/SFTD, ROBO, CBIO and TECA.

## 3. Pattern analysis — what the KCF projects that placed at ISEF share

1. **A named vulnerable user group and a single unmet need.** 6/6 Grand-Award winners: blind (×3), aphonic patients, CPR bystanders/first responders, elderly with dementia risk. Every 2023–2026 KCF delegation was ≥60% assistive/health tech. Judges reward "who is helped and how much", not "how big the problem is".
2. **Hardware-in-the-loop or a working artefact the judge can touch.** 4/6 winners are EBED/ROBO devices (glasses, wearable steering, CPR sensor, EMG). The two pure-software winners (HandNBrain, Synchronome) were still *live apps demonstrated on a phone with real-time sensing* (camera gestures / microphone), not dashboards.
3. **A measured human outcome, stated as a number.** VisionGuard: "도착 시간 3배 단축, 충돌 가능성 1/10". Rebeat: compression depth/rate/recoil compliance vs. guideline. HandNBrain: cognitive-activity game tested with elderly users. Synchronome: pitch/tempo error reduction for blind players. None of the winners' headline metric was a model-validation statistic (AUC/F1).
4. **Solo or 2–3-person teams from ordinary schools do win.** Korea Digital Media HS, Kyeongbuk HS, Sunrin, Ilsan Daejin, Osan HS, Okgwa HS (rural Jeonnam) — not the science academies. ISEF judges in EBED/SFTD/TECA are not penalising the absence of a university lab.
5. **What did NOT place:** infrastructure/analytics software with no human study (SupportLess, Crowd Avoider, ALcode, bus reservation, broadcast management, virtual try-on, lab-waste sensor). The pattern is stark: *technically fine tools without an evaluated user outcome got nothing.*
6. **Category reality.** KCF projects have appeared only in EBED, SOFT/SFTD, ROBO, TECA, ENBM. The 과기정통부 mentoring pipeline is explicitly built for those. An EAEV entry from KCF has no precedent; the 2026 YSC-route SFTD059T evacuation project shows evacuation/incident software is judged in **SFTD (Software Design)**.
7. **Middle/9th-grade wins exist** (HandNBrain 2025, Synchronome/Redi-up 2026), so grade level is not a barrier; polish and evidence are.
8. **Ceiling so far: 2nd place, once.** No KCF project has taken 1st or Best-of-Category. The gap between "4th" and "top" projects at ISEF is usually rigor of validation (baselines, ablations, real deployments), which is where WildfireGuardian's LOGO-CV and NUMBERS.json discipline is an actual edge.

### Concrete implications for WildfireGuardian

- **Finals positioning (KCF 10/24).** Lead with the *person*: a rural elderly household in 의성/안동-type terrain, the operator console assigning a rescue vehicle, and the measurable delta (evacuation minutes saved / households reached before fire arrival vs. a naive shortest-path baseline). Put AUC 0.89 and LOGO-CV in the "scientific principle" answer for Q&A, not on the headline. Judges in this pipeline (and the KCF rubric's 구현 및 유용성/사회 기여) reward human outcome + demonstrable artefact; five of six Grand-Award precedents had it.
- **Add a human-validation artefact before ISEF selection (Dec).** The precedents that won all had one: get `docs/firefighter_consultation.md` upgraded to a structured expert evaluation (n≥3 firefighters/공무원 rating route plausibility) or a small tabletop exercise with elderly participants/이장. Even a 5-person structured usability/route-acceptance study moves the project from the "no award" cluster to the winning cluster.
- **Make the demo tangible.** Offline `web/finals.html` is fine for KCF, but consider a physical element for ISEF: a printed 3-D terrain or a tablet with live FIRMS trigger replay. Every Grand-Award precedent gave judges something to interact with in real time.
- **Category choice.** Enter **SFTD (Software Design)** — it is where the KCF mentoring pipeline, the 2026 YSC evacuation-routing precedent (SFTD059T), and the AAAI/Midjourney/HP special-award sponsors sit. EAEV would isolate the project from the KCF support track and pit it against science-academy field-data projects with no software-judging culture. If the household-level rescue routing gets a hardware/edge element (e.g., an offline beacon for elderly homes), EBED becomes an option — EBED is where KCF's two best results (2nd, 4th, 4th) came from.
- **Differentiate from SFTD059T explicitly** in one slide/board panel: FDS (indoor fire dynamics) vs. wildfire spread ML on Korean fires; building egress vs. household-level rural evacuation + rescue vehicle dispatch on a time-expanded graph; static visualisation vs. live FIRMS trigger. Judges may remember the 2026 project.
- **Do not contradict the submitted 서식1/2 purpose** (KCF rule); the assistive/rescue framing is already in the submitted purpose (rural elderly evacuation), so sharpening it is safe; a pivot to "environmental mapping" is not.
- **Grand-Award ceiling implies the bar for ISEF top-3 is validation rigor**: keep `make verify`-gated numbers, add a baseline comparison table (naive routing vs. WildfireGuardian) and an ablation (fire model on/off) — this is the one place where WildfireGuardian can exceed every KCF precedent.
