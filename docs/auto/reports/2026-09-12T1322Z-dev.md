### 1. WFG-256 — the rotation null

**The question.** `docs/disc_null.md` and Q36 (tier T0) report that the forward-simulated
core beats the area-matched disc by **2.2044** seed-removed. Nothing in the repository could
say what that ratio was made of, so 「그 2.2배가 모양을 맞혀서입니까, 원이 아니라서입니까?」
had no answer and WFG-254 had to strike 「모양」 off the card as an axis the model was said to
have won.

**The null, pre-registered in the claim commit `f250e3b` before the script existed.** Hold
the model's own shape and cell count fixed; rotate that mask rigidly about the centroid of
the `t = 0` seed (**97.7751**, **55.1205** — the same centre `measure_disc_null.py` asserts
and uses, and the only one that uses no information the model did not have) through every
**15** degrees with 0 excluded (**23** rotations); re-rasterise on the canonical 181×156 /
500 m grid by inverse nearest-neighbour; score against the same observation under the same
nearest-observation matching and the same `p_cut`, raw and seed-removed. Zero free
parameters. The scorer is **imported** from `scripts/measure_disc_null.py`, not copied, so
the two comparisons cannot drift — `tests/test_rotation_null.py` asserts that the function
is defined in the disc null's file and that this script contains no `def _score`.

**Result, at the headline slice (360 min vs 333 min, gap 27, 952 cells — the same pair and
the same selection rule the disc null fixes), seed removed:**

| | seed-removed IoU |
|---|---|
| the core **as oriented** | **0.2577** |
| **best** of the 23 rotations | **0.1359** |
| **median** of the 23 | **0.0746** |
| **worst** of the 23 | **0.0387** |
