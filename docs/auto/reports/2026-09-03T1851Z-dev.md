## The root objection, and what it changed

The `hate` pass on my own plan produced one objection that changed the build.

The figures in the row (n = 300, 84.5%, 63.9% …) entered this repository through a
**scratchpad text extraction that no longer exists in the tree** — the row says so
itself. Writing them into an evidence doc and stamping the PDF's sha256 beside them
would produce a number that *looks* sourced while the checksum authenticates **the
PDF, not the transcription**. That is exactly HANDOFF §4-B's failure class with a
checksum on top, and it is the class this project's credibility record is built on
catching.

Cheapest test: extract the PDF's own text and check every figure against it
mechanically. That test was run and it became the deliverable — the transcription is
now done by a program rather than by hand.

## In plain terms

regional rate. We also had "8 died at Yeongdeok" in our notes; it is 10, and that
