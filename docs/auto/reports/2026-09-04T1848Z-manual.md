## Why only on GitHub

The test grades the WFG-067 stamp gate against five ways a commit id can be wrong. One of the
five — the case the row exists for — is a commit a rebase left unreachable, so the test has to
manufacture one with `git commit-tree`.

Every other `git` call in that file **reads** the object database. That one **writes**, and git
will not write a commit object without a committer identity. The identity was inherited from
the machine, and that is the entire difference:

| | identity | probe |
|---|---|---|
| cloud sandbox / laptop | global `user.name` + `user.email` present | built; gate grades 5 cases; PASS |
| GitHub Actions runner | `actions/checkout` sets neither; auto-detection gives `runner@<host>.(none)` | `commit-tree` refuses, prints nothing; FAIL |

So the gate was green on every machine that can create the defect and red only on the
independent check. The CI log said just `assert ''`, because the original assertion swallowed
git's exit code and stderr.

The boundary is measured, not inferred. The test arrived in `deeb147`;
`git merge-base --is-ancestor deeb147 fdab7bc` is false (run 85, the last green) and
`… deeb147 201c554` is true (run 86, the first red). The test's own arrival is the line
between green and red.

## Reproduced, and the fix verified, without a runner

The failure reproduces here by removing the one piece of environment the runner lacks:

```
env GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_SYSTEM=/dev/null \
    GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=user.useConfigOnly GIT_CONFIG_VALUE_0=true
```

Under that environment the pre-fix command form dies with `fatal: no email was given and
auto-detection is disabled`. With `21b8740` checked out, the two WFG-067 tests pass under the
same environment. Both directions were measured. That is the check that matters here, because
the fix's whole claim is about a machine that has no identity, and it is not a claim the
ordinary suite run can test.

`commit-tree` is the only git **write** in the entire suite
(`grep -rn "commit-tree\|hash-object" tests/ scripts/`), so the class is closed, not just the
instance.
