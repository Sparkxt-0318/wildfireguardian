`check_paper.py` now writes and checks `built_pages_inputs`: a digest of the document the
count was measured on — the ordered figure list with each PNG's pixel size, the table

**What that is, at its true size** (the first version of this lap claimed more, see
below): it does **not** re-derive the page count and nothing in `paper/` can — only a

every field in it is forgeable by the lap the gate audits. What it buys is that a figure
or a block of prose arriving unnoticed turns the gate red instead of quietly invalidating
a number nobody rechecks, and that keeping the old count anyway becomes an edit visible
in the diff rather than an accident. **WFG-116's first alternative — one `apt` line in
`auto-gates.yml` so a clean clone measures — is the fix that re-derives, is outside
`paper/`, and is still open.**

Two design decisions, both recorded in `paper/README.md`:

- **Pixel sizes, not PNG bytes.** `style.py` falls back through a font list, so the same
