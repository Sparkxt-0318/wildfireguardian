## 과제 1 — 위험원 민감도 (이월된 Phase 1c)

`TrainedModelHazard` 를 **영덕 전용**으로 구현했습니다. 가상 발화 셀 하나를
`initial_active` 로 놓고 `spread_v2.forward_simulate` 를 돌린 뒤,
`HazardSequence` 로 재표집합니다. 영덕에는 ERA5·DEM·연료가 모두 있으므로
가능하고, Paradise 에는 없으므로 불가능합니다 — 이것이 Session 14 에서
이 비교를 하지 못한 이유이자, **이 클래스가 모델을 이식 가능하게 만들지
않는다**는 뜻입니다.

⚠ **기상을 맞췄습니다.** 학습 모델은 시뮬레이션 시계에서 ERA5 를 읽으므로,
타원 위험원에도 **같은 ERA5 바람**(풍속 `matched_weather` 참조)을 넣었습니다.
합성 시나리오를 그대로 썼다면 위험원 모델과 기상 출처가 섞여 어느 쪽에도
차이를 귀속시킬 수 없습니다.

| | 타원 물리 | 학습 spread_v2 |
|---|---:|---:|
| 취약도 평균 | 0.1935 | **0.1956** |
| 실패 이력 가구 | 24 / 124 | **25 / 124** |
| 순위 상수인가 | 아니오 | 아니오 |

**순위 상관 (Spearman) = 0.9915.** 정의됩니다 — 어느 쪽도 상수가 아닙니다.

### 꼬리까지 일치합니다

| | 가구 수 |
|---|---:|
| 양쪽에서 실패 | **24** |
| 학습 모델에서만 실패 | **1** |
| 타원에서만 실패 | **0** |
| 양쪽에서 실패 없음 | 99 |
| 점수가 조금이라도 바뀐 가구 | **1** |

**높은 상관 + 일치하는 꼬리**입니다. 지시서가 구별하라고 한 두 경우 중
강한 쪽입니다 — 구조적으로 전혀 다른 두 위험원 모델(해석적 타원 이동시간
전선 대 gradient boosting 확률 모델)이 **사실상 같은 가구 순위**를 냅니다.

**해석:** 이 층의 출력은 **기하**(가구·피난처·도로가 어디 있는가)가
지배하며 화재 물리는 거의 기여하지 않습니다. 피난처 태그 교정이 0.000 →
0.194 를 만든 것과 위험원 교체가 1가구만 바꾼 것은 같은 이야기의 양면입니다.

⚠ **어느 위험원이 옳다는 주장이 아닙니다.** 측정한 것은 순위가 위험원 선택에
얼마나 의존하는가뿐입니다.
⚠ **학습 모델은 영덕을 포함한 6개 화재로 적합되었으므로 영덕에서 in-sample**
입니다. 미지 화재에서의 거동은 이보다 나쁠 것입니다.

## 과제 2 — 지평 스윕: **이 층의 1차 가정**

### 영덕

| 지평(분) | 취약도 평균 | 실패 이력 가구 | 240분 대비 순위 ρ |
|---:|---:|---:|---:|
| 30 | **0.5081** | 63 | **0.333** |
| 60 | 0.4032 | 50 | 0.515 |
| 120 | 0.2903 | 36 | 0.723 |
| 180 | 0.2177 | 27 | 0.893 |
| **240** | 0.1935 | 24 | 1.000 |
| 360 | 0.0645 | 8 | 0.668 |

### Paradise

| 지평(분) | 취약도 평균 | 실패 이력 가구 | 240분 대비 순위 ρ |
|---:|---:|---:|---:|
| 30 | **0.4904** | 485 | **0.310** |
| 60 | 0.2523 | 254 | 0.686 |
| 120 | 0.0121 | 42 | 1.000 |
| 240 | 0.0101 | 40 | 1.000 |
| 360 | 0.0101 | 40 | 1.000 |

### ⚠ 순위는 지평에 걸쳐 안정적이지 **않습니다**

지시서가 바랐던 성질 — "절대값은 움직여도 최악 가구는 같다" — 은 **성립하지
않습니다.** 영덕에서 30분 대 240분 순위 상관은 **0.333** 입니다.
**지평을 고정하지 않으면 이 층은 우선순위 지정에 쓸 수 없습니다.**

360분에서 ρ 가 0.668 로 다시 떨어지는 것은 실패 가구가 8개뿐이라 순위가
동률로 채워지기 때문입니다.

### 지평 효과는 사이트 고유가 아닙니다

두 사이트 모두 **같은 모양**입니다: 단조 감소, 짧은 지평에서 순위 불안정.
그리고 **30분에서는 두 사이트가 거의 같습니다** (영덕 0.508 대 Paradise
0.490). **두 사이트는 긴 지평에서만 갈라집니다** — Paradise 는 120분 이후
포화(ρ=1.0, 40가구 고정)하는 반면 영덕은 계속 움직입니다. Session 14 의
"영덕이 Paradise 보다 취약하다"는 관찰은 **긴 지평의 성질**이지 사이트의
성질이 아닙니다.

### 기본값 정당화 — **임의이되 스윕됨(arbitrary-but-swept)**

기본값 **240분**을 유지하되, **근거를 확보하지 못했음을 명시**합니다.

- **지평은 화재의 수명이 아닙니다.** 이 데이터셋의 화재는 **40–252시간**
  탔습니다 (`docs/SESSION10_LOG.md` §0.6). 240분은 그것의 2–10 % 입니다.
  지평은 **도보 자력 대피가 여전히 옳은 질문인 시간 창**이라는 행동적
  선택입니다.
- **근거가 될 수 있었던 데이터.** 산림청 국가산불정보시스템 산불통계는
  **진화시작시간·진화완료시간**을 기록하며 진화 소요 시간이 표준 지표에
  포함됩니다. **그 값을 이번 세션에서 취득하지 못했습니다.**
- 따라서 240분은 **임의이되 스윕된 값**으로 표시하고, 위 표를 항상 함께
  제시합니다.

## 과제 3 — 망 구조 가설: **지지되지 않습니다**

### 차수 분포와 독립 탈출 경로

| | 영덕 | Paradise |
|---|---:|---:|
| 보행 노드 | 8,443급 | 2,372 |
| 평균 차수 | **5.207** | 2.340 |
| 차수 1 비율 (막다른 길) | **0.0 %** | **33.3 %** |
| 차수 2 비율 | — | — |
| **가구당 독립 탈출 경로 평균** | **1.976** | **1.515** |
| 경로 중앙값 | 2 | 1 |
| 경로 1개 이하 비율 | **41.9 %** | **63.3 %** |
| 취약도 평균 (240분) | **0.194** | 0.0089 |

**Paradise 가 모든 연결성 지표에서 더 나쁩니다** — 막다른 길이 1/3,
독립 탈출 경로가 더 적고, 63 %가 사실상 단일 경로 — **그런데 취약도는
22배 낮습니다.** 가설은 정확히 반대 순서를 예측합니다.

### 결정적 증거는 사이트 내부 상관입니다

> **영덕 내부: 탈출 경로 수와 취약도의 Spearman = +0.048**

가설은 **음의 상관**(경로가 적을수록 취약)을 예측합니다. 측정값은 0 에
가깝고 **부호도 반대**입니다. **사이트 내부에서도 지지되지 않습니다.**

지시서의 지시대로, 판정 근거는 이 사이트 내부 상관이며 **N=2 교차 사이트
비교는 가설의 검정으로 취급하지 않습니다.**

⚠ **차수 비교에는 교란이 있습니다.** 영덕 망은 `build_walk_network` 로
만들어져 병렬 OSM 간선을 병합하고 60 m 간격으로 재표집하지만, Paradise 망은
osmnx MultiDiGraph 를 그대로 `nx.Graph` 로 접은 것입니다. 서로 다른 코드
경로가 차수를 다르게 만듭니다. **탈출 경로 수**는 피난처에 대한 위상량이라
상대적으로 덜 교란되지만, 완전히 자유롭지는 않습니다.

### 그래서 무엇이 차이를 만드는가 — **여전히 모릅니다**

죽은 가설이 이제 둘입니다: **피난처 밀도**(Session 14 후속), **망 구조**
(본 세션). 과제 2 는 세 번째 후보를 제시합니다 — **차이가 긴 지평에서만
나타난다**는 것 — 이지만 그것은 현상의 재기술이지 설명이 아닙니다.

## 과제 4 — OSM 태깅 발견을 이식성 결과로 기록

`docs/global_portability.md` §3b 에 명명된 발견으로 추가했습니다:
**피난처 태그 어휘는 지역마다 다르며, 나라별로 검증해야 합니다.**

질의한 태그(`amenity=shelter|community_centre`, `leisure=park`), 돌아온 것
(공원 33 + 정자 17), 놓친 것(`amenity=townhall` 33 = 마을회관·읍사무소,
`amenity=school` 11, `amenity=hospital` 2), 그리고 그 한 태그가 만든 차이
(0.000 → 0.194)를 수치와 함께 적었습니다. 일반화 지침 세 가지(가정하지 말고
검증할 것, 거짓 양성과 거짓 음성을 **둘 다** 볼 것, 이름을 읽을 것)와
⚠ 한계(`amenity=townhall` 은 **구조 유형**만 식별하며 내화성·개방 여부·
수용 인원은 미상)를 함께 기록했습니다.

## 주장하고 싶었으나 검증하지 못한 것

**이월된 세 항목 (Session 14 후속에서 열린 채 남은 것):**

1. **발화 개수 8 → 4.** 예산 때문에 줄였고 **본 세션에서도 4개**입니다.
   모든 영덕·Paradise 수치가 4개 발화 위에 있습니다. 표집이 거칠수록
   추정도 거칩니다.
2. **도착 시점 기준 생존 버퍼 변형** — 여전히 **미구현**입니다. 발화 시점
   기준만 구현·스윕했습니다.
3. **정자가 실제로 높은 비율로 소실되는지** — 여전히 **미확인**입니다.
   구조(벽 없는 목조)에 근거한 판단이며 한국 산불에서의 소실률 통계를
   확인하지 않았습니다.

**본 세션에서 새로 생긴 것:**

4. **240분 기본값의 근거.** 산림청 진화 소요 시간 통계가 존재함은
   확인했으나 **값을 취득하지 못했습니다.** 기본값은 임의이되 스윕된
   값입니다.
5. **차수 비교의 교란.** 두 사이트의 보행망이 서로 다른 코드 경로로
   만들어졌습니다. 같은 경로로 다시 만들어 비교하지 **않았습니다.**
6. **학습 위험원의 in-sample 성격.** 영덕을 포함해 적합했으므로 낙관
   편향이 있습니다. 영덕을 제외하고 적합한 모델로 다시 돌리지
   **않았습니다.**
7. **위험원 순위 상관 0.9915 의 일반성.** 발화 4개·기상 1개·사이트 1개
   에서의 값입니다. 다른 기상이나 더 강한 화재에서 두 위험원이 갈라지는지
   **모릅니다.**
8. **영덕/Paradise 차이의 원인.** 가설 두 개가 죽었고 **대체 설명이
   없습니다.** 긴 지평에서만 갈라진다는 관찰은 재기술이지 설명이 아닙니다.
9. **`forward_simulate` 의 단일 셀 시드.** 실제 발화는 점이 아니며,
   1시간 스텝·500 m 셀에서 단일 셀 시드가 만드는 초기 편향을 **측정하지
   않았습니다.**
