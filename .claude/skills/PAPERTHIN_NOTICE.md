# Vendored skills — paperthin

The skill directories listed below are vendored verbatim from
https://github.com/LilMGenius/paperthin (MIT License, © LilMGenius), version
0.17.4, commit 3bca079, on 2026-09-03. They are copied rather than symlinked so
that a fresh cloud checkout of this repository carries them without a network
install step. Upstream LICENSE and NOTICE are reproduced in
`.claude/skills/paperthin-LICENSE` and `.claude/skills/paperthin-NOTICE`.

To refresh: `npx skills@latest add LilMGenius/paperthin` locally, or re-copy
`skills/<perspective>/<name>/` from a fresh clone into `.claude/skills/<name>/`.
