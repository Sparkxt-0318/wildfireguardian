# Research evidence

`routing/` contains the independently accepted latest-input 80-execution result set and six reviewed figures with editable SVG, PNG, PDF, source tables and captions. `forecast/` contains the completed, separately frozen forecasting-ablation methods and findings. Different inputs, checkpoints, incidents and repetitions are not pooled.

The final GitHub release carries full original evidence archives, including failures and reproduction records. No newly fitted ablation model replaces checkpoint c651. The four-scale model's general superiority was not demonstrated; see the forecast handoff for the positive and negative findings.

Primary routing metric: verified on-time resolution. Candidate 20/20 missions (15 route, five scoped refusal); reference 13/20. This is not routing accuracy, measured physical safety or 20 completed evacuation journeys.
