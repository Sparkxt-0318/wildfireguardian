# Kill-shot sections

One file per direction, `<direction>.md`, built from
`research/eval/KILLSHOT_TEMPLATE.md`. Items 1 to 4 of a direction's file are
written before any result exists and are not edited afterwards; items 5 to 7 are
appended after the result.

The template's seeded priors for all three directions are in the template itself,
dated 2026-09-16, written before any pre-registration was received. When a
direction's own file is opened, the prior is copied into it unchanged so that the
two can be compared later.
