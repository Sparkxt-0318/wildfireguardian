# Source-clock scope for a possible contact scaling study

The source-bound metadata readout in KNOWN_FOOTPRINT_SOURCE_PRECONDITIONS.json verifies all 20 original Korean packet metadata hashes. Each declares uniform sub-hour timing, construction seed 20261008, horizon H = 3,600 seconds and scalar duration T = 3,970.4642815249267 seconds. The prepared contact-only scaling protocol can inherit these exact settings, including the existing present-fire max-remaining enclosure, while retaining all original saved trajectory identities. This does not authorize an adapter or a timed study. The JSON embeds the exact read-only extraction program and its hash; no graph is parsed, trajectory simulated or solver called in that extraction.

These inputs also limit the fragmentation claim one can test. A newly ignited cell has activity [b,b+T), with b >= 0 and b+T > H. For a full traversal of duration D, supported departure times satisfy 0 <= t <= H-D. Each copied chord occupancy occupies that cell from t+D*z_a through t+D*z_b, with 0 <= z_a <= z_b <= 1. Its upper activity-overlap condition t+D*z_a < b+T is automatic because t+D*z_a <= H < b+T. Its remaining condition is t+D*z_b >= b. Thus its unsafe departures form a tail of the supported departure lattice. Taking the union across occupancies and members gives another tail.

The shared present-fire intervals [0,R) instead block departure prefixes: t+D*z_a < R, with the lower overlap condition automatic for nonnegative time. Their union is a prefix. A support barrier blocks the entire departure domain. Consequently the complement of the combined prefix and tail has at most one safe full-traversal departure interval per edge under this particular scalar one-hour construction, independently of K. Closed cut-point occupancies obey the same inequalities. Empty domains and wholly blocked edges are included in this statement.

This does not establish any measured state count or speed. Destination openings can have their own partitions, nonwaitable configurations retain restricted-dominance time labels, and changing the tail threshold changes which parts of the graph are reachable. Search counters and times can still vary with K, in either direction. It does establish why these actual inputs cannot be assumed to demonstrate increasing multi-interval edge fragmentation as members are added. A future states-versus-K figure must report the observed counters and this source limitation. The lemma does not extend to longer forecast horizons, shorter or different residence laws, reignition or arbitrary multi-phase fire models.
