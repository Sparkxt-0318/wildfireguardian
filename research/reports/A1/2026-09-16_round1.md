  not be confirmed. `https://map.ngii.go.kr/ms/map/NlipMap.do` and
  `https://map.ngii.go.kr/` both returned HTTP 400 to a page fetch, and
  `https://www.ngii.go.kr/kor/content.do?menuNo=3000353` returned a page with
  no procedural detail. Two alternative routes were tried per the failure
  policy and both fell short; this was not looped further. See the human-gate
  list below.
- `kigam_geology_map` and `naas_soil_map` licence terms were not fully
  resolved; both point to a "request" or "terms" page that was not read in
  full, since the immediate need (access mode: request-based) was already
  confirmed.
- `kfs_forest_type_map`'s licence is KOGL Type 3, which forbids modification
  of the work. This program's intended use (deriving a pine/broadleaf
  covariate from the forest type map) may or may not count as "modification"
  under that licence. This is flagged in the registry's `known_issues` but
  not resolved; it may need a human reading of the licence before any derived
  layer from this dataset is shared outside this repository.
- The KFS Open API probe (T1.3) has not actually run against the real
  endpoint; it is untested against the live service and could still fail in
  a way this agent could not anticipate (rate limiting, a different
  parameter schema, a different response envelope) once a key is available.
- The Sancheong landslide inventory citation given in this task
  ("Landslides 23:2363-2381") and the citation already on
  `research/TASKBOARD.md` (which additionally names the year "2026") were not
  independently cross-checked against the published paper; whoever sends the
  letter should confirm the exact title, DOI and author details first.
