## V2 admission boundary

The recognizer first recomputes immutable and current whole-P SHA-256 values from the actual source strings. Only enumerated pairs against exact current P88 are eligible. Unknown loader/global/decorator/source versions refuse. This is not a caller-supplied hash assertion.

_schedule_contract additionally binds the exact intended phase/variant/stage, requires its exact known complete source profile, obtains every preserved source byte with _source_blob and recomputes every hash. Unknown/missing/extra/differently assigned versions refuse. Every current dependency must match the reviewed baseline. The executing and root auditor numerical/member surfaces remain identical to the baseline except this explicitly scoped repair and exact added schedule-context kwargs. RUN_PROTOCOL's immutable SPLIT pin must match current SPLIT bytes.

These checks do not replace independent full raw-source/cache membership, values, dtype, names/schema and ordering authentication. Those unchanged gates run before compatibility is used by audit_coverage. They do not retrospectively claim old checks executed, runtime IDs were logged, or actual data/model behavior was replayed. Runtime/dependency checks elsewhere remain mandatory. No data-based exception is permitted for an unknown code version, wrong UTC recipe, model, crop, budget, population or optimizer path.
