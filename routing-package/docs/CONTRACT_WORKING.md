# Agreed implementation contract (new adapter; frozen benchmark semantics retained separately)
Package routing/ uses standard library only. All core data are JSON dictionaries. Units seconds, kW/m2, kJ/m2. Piecewise constant right-continuous hazards; positive-duration occupancy includes endpoint flame/peak checks; final support endpoint uses last interval value. Exposure route+wait only by default, destination dwell gated separately; request exposure_scope='including_dwell' explicitly adds dwell dose. No physical safety claim.

Graph: {revision,crs,grid:{x0,y0,resolution,width,height},nodes:[{id,x,y,waitable}],edges:[{id,u,v,travel_ticks,segments:[{cell,start,end}],reverse_edge?:id}],forbidden_turns:[[incoming,outgoing]],mid_edge_reversal:false}. Grid cells integer row-major; segments contiguous covering [0,1], representing complete raster intersection of directed-road geometry (straight edges tonight); graph validator checks coordinate-derived cell intersections and reverse geometry. Turn rules explicitly declared including empty list. No implicit U-turn ban. Positive integer edge travel_ticks and dt seconds. Best-case passability.

Hazard: {schema:'wfg.routing.edgegrid/1',version:int,graph_revision,crs,grid,dt,issued_at,available_at,valid_from,valid_until,evidence_class:'LABELLED_FIXTURE'|'MENTOR_FORECAST',provenance:{source,interpretation},channels:['flame_contact','incident_heat_flux'],unsupported_channels:[...],members:[{id,breakpoints:[seconds],flux:[[cell quantities] per interval],flame:[[bool per cell] per interval],support:[[bool per cell] per interval]}]}. Arrays fully dimensioned. No probability/arrival/intensity conversion. Breakpoints cover declared validity; quantity is incident heat flux on vehicle proxy at road-grid cells. UTC timestamp metadata may use ISO8601; validity/breakpoints mission seconds in common documented time_origin ISO8601 field. issued_at and available_at ISO times compare to request.as_of ISO. Missing support may exist but must never become zero. Mentor payload pending.

Request: {position:{node:id}|{edge:id,fraction:0..1},incoming_edge:id|null,departure:seconds,horizon:seconds,destinations:[{node:id,dwell:seconds,open_intervals:[[seconds,seconds]]}],incurred:{member_id:nonnegative dose},hazard_version:int,as_of:ISO8601,objective:'earliest_arrival',exposure_scope:'route_only'|'including_dwell',budgets:{peak:nonnegative,dose:{member_id:nonnegative}},limits:{wall_s,max_labels,max_expansions,frontier_width},solver:'baseline'|'astar'|'dijkstra'|'activation'}. dt lattice anchors time_origin; departure/horizon/dwell/window endpoints lattice aligned for integration. Position edge fraction uses residual ceil ticks, documented slower partial traversal; incoming context MUST equal edge for mid-edge. Incurrence exact member map; missing/new identities unsupported unless explicitly supplied conservative mapping at session boundary.

Public functions:
- validation.validate_graph(graph)->graph copy or ValidationError(code,message)
- validation.validate_hazard(graph,hazard,as_of=None)->hazard copy or ValidationError
- validation.validate_request(graph,hazard,request)->request copy or ValidationError
- core.solve(graph,hazard,request)->result dict; does validation and independent.check_route for returned route. Baseline full exact time-layer vector solver, maintained as integration default; activation is selectable specialized variant, established historical baseline kept in legacy_bridge for benchmark and claims. Neither new adapter nor tests promote a road-scale challenger.
- core.check_route(graph,hazard,request,legs,destination)-> dict with ok,status,codes,per_member,arrival (candidate internal helper optional; independent checker mandatory before checked result)
- independent.check_route(graph,hazard,request,legs,destination)->same independent reimplementation; no core import or candidate cost/dominance reuse.
- independent.exhaustive(graph,hazard,request,max_walks=200000)->{status,arrival,legs,...}, no dominance.
- fallback.checked_return(graph,hazard,request,history,endpoint,dwell=0)->result; history list chronological {edge,from_fraction:0,to_fraction:1}; current partial must match history; no teleport or generic reverse shortest-path substitute.
- session.RoutingSession(graph): accept_update(hazard,as_of)->event; plan(request)->result; commit(result)->bool checks hazard version and request generation; set_progress(position,incoming_edge,departure,incurred,history)->event; reset()->event. History membership identity change with nonzero dose is UNSUPPORTED unless explicit conservative mapping. Old accepted plans always rechecked before display; rejected/stale updates explicit, no silent old current guidance.

Legs: {kind:'EDGE',edge:id,start:seconds,end:seconds,from_fraction:0,to_fraction:1} or {kind:'WAIT',node:id,start,end}. Result: {status:'CHECKED_ROUTE'|'CONDITIONAL_OPTIMUM'|'PROVEN_INFEASIBLE'|'UNSUPPORTED'|'TIMEOUT'|'AT_ISSUE_FAILURE'|'DISCONNECTED'|'INVALID_INPUT',reason,legs,arrival,destination,per_member,solver_status,metrics,provenance,certificate_conditions,hazard_version}. Reference noncompletion UNRESOLVED. Missing global support must prevent PROVEN_INFEASIBLE; admissible complete route can be checked under partial support but optimality withheld conservatively. At issue hazard violation distinguish. Full feasible set includes cycles and all lattice waits permitted only at waitable nodes. Destination admission at start or edge arrival only; waiting at a destination does not create a new admission event. Dwell interval [arrival,arrival+dwell] flame/peak checked, declared opening end inclusive.

Ownership: root validation.py, contract/docs/preservation/legacy packaging. A core.py and tests/test_core.py only. B fallback.py, session.py, replay.py, tests/test_session_fallback.py only. C independent.py, tests/test_independent.py, fixtures/evaluation_cases.json and mathematical review only. D later source audit/fresh edge-case cross-review. E later benchmark driver/performance only. Agents are not alone; preserve others' edits. Cross-module changes ask coordinator. Light tiny checks (<10s CPU) allowed; all road/heavy checks use existing coordination/run_locked.py; official timings exclusive. Never read specialized sealed final sets or alter scientific eligibility.
